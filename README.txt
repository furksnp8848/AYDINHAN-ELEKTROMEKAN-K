AYDINHAN ELEKTROMEKANİK — Statik Web Sitesi (HTML / CSS / JavaScript)

İçerik:
  index.html, hakkimizda.html, hizmetlerimiz.html, projelerimiz.html, iletisim.html
  style.css        -> tüm tasarım (lacivert/beyaz/gri kurumsal palet, mobil uyumlu)
  script.js        -> menü, kaydırma efektleri, animasyon, proje galerisi (lightbox)

Kurulum:

  2) Ana dizinde index.html bulunmalıdır. Başka bir işlem gerekmez (build yok).
  Yerelde denemek için index.html dosyasını tarayıcıda açın.
